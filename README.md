# Krish Jaiswal — Portfolio

Personal portfolio for [Krish Jaiswal](https://github.com/KrishJ4856), built with Next.js, TypeScript, Tailwind CSS, and Shadcn UI.

## Run locally

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
bun run build
```
