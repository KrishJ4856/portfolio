## Overview

CustomDocs turns a topic into a complete set of structured documentation. A planning agent creates the hierarchy, a writing agent produces the content, and the finished result opens in a professional three-column documentation reader.

## Highlights

- AI planning and writing workflow powered by Mastra
- Three-column reader with navigation and an in-page table of contents
- Eight built-in themes plus custom Google Fonts
- Markdown rendering with code highlighting, tables, and blockquotes
- Clerk authentication and encrypted bring-your-own API keys

## Stack

Next.js 16, TypeScript, MongoDB, Mongoose, Clerk, Mastra, DeepSeek, Tailwind CSS, and React Markdown.
