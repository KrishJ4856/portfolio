## Overview

IdeaToPrototype simulates a compact product team in the terminal. It accepts a single app idea, researches the market, interviews the user about the MVP, writes a product requirements document, generates the frontend, and deploys the result to Vercel.

## Workflow

1. Analyze the idea and competing products.
2. Ask focused product questions.
3. Define the MVP and frontend architecture.
4. Generate the application code.
5. Deploy and return a shareable URL.

## Stack

TypeScript, Node.js, Mastra, Google Gemini, web research, and the Vercel API.
