## Overview

This project brings a warm, high-contrast Linga Bhairavi visual system to Omarchy. Crimson, gold, green, and near-black tones are assigned clear roles across application surfaces, focus states, notifications, and the lock screen.

## Companion widget

The QML Stuti widget places a small lotus in the status area. It opens a compact panel containing the complete Stuti, highlights lines on hover, and links to the official Sounds of Isha recording.

## Details

- Five curated wallpapers with sensible defaults
- Hyprland styling, application colors, and shell surface tuning
- Repeatable install and update scripts
- Separate, installable Omarchy plugin for the Stuti widget
