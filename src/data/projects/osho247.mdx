## Overview

Osho247 is a deliberately minimal talk player built with the official YouTube IFrame Player API. It keeps the experience focused and stores playback progress locally in the browser, without requiring an account or database.

## Approach

- A small, curated public video catalogue
- Browser-only progress using local storage
- A data layer designed to support a future database-backed editor
- A responsive interface optimized around listening
