## Overview

Task Manager CLI is an installable Node.js tool for managing todos without leaving the terminal. It supports creating one or more tasks, reading the current list, updating a task by its code, and deleting completed or unwanted work.

## Commands

- `todo add`
- `todo read`
- `todo update`
- `todo delete`

The project uses Commander.js for its command interface and MongoDB for persistent storage.
